# Inventario Empresarial — Punto de Venta

**Aplicación Android | Inventario y gestión de ventas**

Sistema de gestión de inventario y punto de venta desarrollado originalmente como aplicación web y adaptado a Android mediante APK.

Diseñado para facilitar el control de productos, existencias, movimientos de inventario y registro de ventas desde un dispositivo móvil.

**Estado del proyecto:** En desarrollo activo.

---

## Aviso importante

Antes de instalar y utilizar esta aplicación, ten en cuenta las siguientes consideraciones:

### 1. Sin facturación electrónica

Esta aplicación **NO cuenta con integración de facturación electrónica con SUNAT**.

Los tickets o comprobantes generados son únicamente documentos de control interno y no reemplazan facturas, boletas electrónicas u otros comprobantes de pago autorizados.

### 2. Almacenamiento local

La aplicación funciona con almacenamiento local del dispositivo.

- No utiliza una base de datos en la nube ni un servidor remoto.
- La información se almacena directamente en el dispositivo donde se utiliza.
- Los datos no se sincronizan automáticamente con otros dispositivos.
- No existe una cuenta en línea que permita recuperar automáticamente la información.

**Importante:** Si desinstalas la aplicación, pierdes tu celular, restableces el dispositivo de fábrica o se eliminan sus datos, podrías perder definitivamente toda la información registrada.

Por ejemplo, si tienes 500 productos y 200 ventas registradas y pierdes tu celular, no podrás recuperar esos registros salvo que hayas guardado previamente una copia de seguridad externa compatible.

La aplicación dispone de funciones de respaldo y exportación a Excel. Se recomienda descargar periódicamente una copia y conservarla fuera del dispositivo.

**Las copias guardadas únicamente dentro del celular también pueden perderse.**

### 3. Software en desarrollo

Este proyecto se encuentra en desarrollo activo y mejora continua.

Pueden existir errores, limitaciones, cambios de funcionamiento o funcionalidades pendientes de implementación.

Se recomienda utilizarlo inicialmente para pruebas o actividades donde se disponga de respaldos periódicos.

## Funcionalidades

La aplicación incorpora herramientas para la gestión de pequeños negocios:

- **Inventario:** registro de productos, categorías, marcas y existencias.
- **Movimientos:** control de entradas y salidas de productos.
- **Punto de venta:** registro de ventas y consulta del historial.
- **Tickets:** generación e impresión de comprobantes internos.
- **Usuarios:** administración de usuarios, roles y permisos.
- **Reportes:** consulta de información operativa.
- **Copias de seguridad:** exportación e importación de información mediante archivos Excel.

La disponibilidad y funcionamiento de determinadas características puede variar según la versión instalada.
